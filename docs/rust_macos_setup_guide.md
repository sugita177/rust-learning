# macOSにおけるRust開発環境セットアップ手順書

macOSでRustの開発環境を構築するための手順と、各コマンドの役割をまとめたドキュメントです。

---

## 1. 仮想環境（Docker等）の要否について

macOSでのRust開発において、Dockerなどの仮想環境は**原則として不要**です。

- **ネイティブ環境のメリット:**
  - Rust公式の管理ツール（`rustup`）がOS環境を汚さずにツールチェーンを一括管理できます。
  - ホストOS上で直接コンパイルすることで、Apple Silicon（Mシリーズ）等のCPUパワーを最大限に活用でき、ビルド時間を大幅に短縮できます。
- **Dockerが必要となる例外ケース:**
  - 最終的なデプロイ先（Linux環境）固有のCライブラリやOpenSSL等の依存関係を厳密に揃えたい場合
  - チーム開発でDB等のミドルウェア構成を同一環境として共有したい場合

---

## 2. 前提ツールの導入（Command Line Tools）

Rustのコードを実行可能ファイル（バイナリ）に仕上げるには、macOSのリンカ（Linker）やCコンパイラが必要です。

### 実行手順
任意のディレクトリ（ホームディレクトリ等）で以下を実行します。

xcode-select --install

### 留意点
- ダイアログ（ポップアップ）が表示されたら「インストール」をクリックして進めます（他のウィンドウの背面に隠れることがあるため注意）。
- インストーラーの残り時間表示は一時的に「数時間」と長めに計算されることがありますが、実際には数分〜10分程度で終了します。
- 以下のコマンドを実行し、パスが表示されれば導入完了です。

xcode-select -p
# 出力例: /Library/Developer/CommandLineTools

## 3. Rustツールチェーン（rustup）の導入

公式インストーラーをダウンロードし、シェルに渡してセットアップを実行します。

### インストールコマンド

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

### コマンドの詳細解説
- curl: ネットワーク経由でデータを転送・取得するツール。
  - --proto '=https': 通信プロトコルを安全なHTTPSのみに制限。
  - --tlsv1.2: 通信暗号化規格をTLS 1.2以上に強制。
  - -sSf: 進捗メーターを非表示（-s）、エラー時はメッセージを表示（-S）、サーバーエラー時に処理を即座に中断（-f）。
- | sh: ダウンロードしたインストーラースクリプトをそのままシェルに渡し、マシンのアーキテクチャに応じた適切なRustバイナリの配置を行います。

### 対話画面の操作
コマンド実行後、ターミナルに対話メニューが表示されます。

1) Proceed with standard installation (default - just press enter)
2) Customize installation
3) Cancel installation

何も入力せずそのまま「Enter」キーを押すと、標準設定（1番）でインストールが進みます。

## 4. 環境変数の反映

インストールした `cargo` や `rustc` などのコマンドを現在のターミナルで即座に使えるようにします。

source "$HOME/.cargo/env"

### 補足
- `$HOME/.cargo/env`: `~/.cargo/bin`（コマンド群の格納先）を検索パス（PATH）に追加するスクリプトです。
- `source`: 指定したファイルを現在のターミナルセッションで読み込んで即時適用するコマンドです。
- ※ 新しく開くターミナルウィンドウでは自動的に反映されるため、手動実行は初回のみで構いません。

### 導入確認
各ツールのバージョンが表示されればセットアップは正常に完了しています。

rustc --version
cargo --version

## 5. 動作テストとプロジェクト作成

新規プロジェクトを作成し、正しくコンパイルと実行ができるか確認します。

### プロジェクト作成と実行

cargo new hello_test
cd hello_test
cargo run

ターミナルに `Hello, world!` と表示されれば、正常に動作しています。

### テスト用ディレクトリの削除
動作確認用フォルダが不要になった場合は、以下を実行して削除します。

# hello_test ディレクトリ内にいる場合:
cd ..
rm -rf hello_test

# 親ディレクトリにいる場合:
rm -rf hello_test

※ `-r` はフォルダ内の再帰的削除、`-f` は確認なしの強制削除を意味します。
